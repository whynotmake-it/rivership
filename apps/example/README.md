# Rivership examples

One app that hosts the example of every Rivership package that has one: Heroine, Motor, coil and Stupid Simple Sheet. It is deployed to GitHub Pages at [https://whynotmake-it.github.io/rivership/](https://whynotmake-it.github.io/rivership/).

Run it on web from this directory:

```sh
flutter run -d chrome
```

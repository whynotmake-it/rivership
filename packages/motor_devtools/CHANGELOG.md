## 0.1.0-dev.0

First preview. Works with motor 2.0 pre-releases only.

 - `MotorDevTools` wraps an app with a draggable bubble that opens a list of every live motor controller.
 - Pause, replay, scrub and slow down one controller or a group.
 - Try another spring or curve on a track, then copy the code. Edits last for the session only.
 - `MotorTimeline` is a read-only timeline widget for docs and demos.
 - Off in release builds by default. `--dart-define=MOTOR_DEVTOOLS=false` removes the code.
